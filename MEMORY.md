# Память проекта ParrotPet

## Текущий статус
Этап 4 готов: волнистый попугайчик (векторный спрайт), полёт с волнами и планированием, зерно и кормление, полный набор анимаций. `dotnet build` — 0 ошибок, 0 предупреждений. Логика (кормление ×3, 5 полётов, падение, режимы Primary и All) прогнана headless-симуляцией на 60 FPS без NaN и выходов за границы; приложение запускается. Визуально (как выглядят спрайт, анимации, зерно) НЕ проверялось.

## Сделано
- Этапы 1–3: WPF-оверлей, трей, FSM, физика, настройки (settings.json), мультимонитор, масштаб, SettingsWindow.
- Этап 4:
  - Обрезка: холст рисования 96×96 (CanvasSize), логический хитбокс 64×64 по центру (поля Pad = 16·Scale), ClipToBounds=False. Окно = 96·Scale и сдвинуто на -Pad; физика и границы считаются по хитбоксу. Перетаскивание считает захват от угла хитбокса.
  - Спрайт: волнистый попугайчик в MainWindow.xaml (салатовое тело, жёлтая голова, полоски на затылке и крыле, синяя восковица, изогнутый клюв, фиолетовые щёчные пятна, 3 точки на горле, ступенчатый хвост). Части с отдельными трансформами: голова, крыло, хвост, грудь (дыхание), глаз (моргание), сердечко.
  - Полёт (MovementService, FlightPhase): Cruise — Безье + синусоидальное колебание по Y (затухает на концах, не выходит за верх экрана), Hover, Descend — планирование smoothstep с мягким касанием. Наклон вперёд 10–25° по скорости, взмахи 10/8/5 Гц.
  - Зерно: Services/FoodService (падение с отскоком на 50–100 px от попугая, Resting, крошки ×3) и Views/FoodWindow (отдельное click-through окно, WS_EX_TRANSPARENT/NOACTIVATE/TOOLWINDOW). Сценарий: «Покормить» в трее → зерно падает → попугай разворачивается, идёт (Walk) и встаёт клювом к зерну → 3 клевка (Eat, 1.8 с) → крошки + сердечко + сытость +20 (ParrotState.Satiety, 0–100, старт 50; показывается в подсказке иконки трея). Одно зерно за раз. Смена монитора вне области убирает зерно.
  - Services/AnimationService: поза = плавное смешивание (0.18 с) между состояниями; Idle — дыхание, повороты головы, чистка пёрышек (раз в 6–12 с), моргание раз в 4–8 с; Walk — переваливание ±5° и хвост; Fall — хвостом вверх (30°) и паническое хлопанье 12 Гц; Dragged — трепыхание; Land — пружина squash&stretch.
  - Случайное «поклевать» убрано: Eat запускается только кормлением.

## Окружение
- SDK 8.0.426 в `%USERPROFILE%\.dotnet` (не в PATH). Сборка: `& "$env:USERPROFILE\.dotnet\dotnet.exe" build`.
- Правило пользователя: после каждого этапа пересобирать exe: `dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish` (нужен .NET 8 Desktop Runtime; publish/ в .gitignore).
